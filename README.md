# localdrop
Partage de fichiers d'appareil à appareil sur le même Wi-Fi, sans cloud ni compte. Scanne un QR code, télécharge ou envoie des fichiers depuis ton navigateur. Windows, macOS et Linux.


## Installation

Rendez-vous dans l'onglet **[Releases](../../releases)** et téléchargez la version adaptée à votre système :

* **Windows :** Téléchargez `LocalDrop.exe` et double-cliquez dessus. *(Si Windows affiche un avertissement SmartScreen, cliquez sur « Informations complémentaires » puis « Exécuter quand même »).*
* **macOS :** Téléchargez `LocalDrop-macos.zip`, décompressez-le, puis faites un **clic droit → Ouvrir** lors du premier lancement.
* **Linux :** Téléchargez `LocalDrop`, rendez-le exécutable (`chmod +x LocalDrop`) puis lancez-le (`./LocalDrop`).

*Alternative avec Python :* `python3 localdrop_app.py` (ajoutez `pip install qrcode` pour l'affichage du QR code).
